# Barista de Café Especial 

Projeto desenvolvido em Kotlin para a atividade de Coding.

O programa simula o preparo de um café especial. O usuário informa o valor do pedido, a quantidade de café, a quantidade de leite e a temperatura. O sistema verifica se a receita está dentro do padrão e calcula a gorjeta de acordo com o resultado.

O usuário possui até 3 tentativas para conseguir preparar a receita perfeita.

## Receita padrão

- Café: 20g
- Leite: 200ml
- Temperatura: 65°C
- Proporção: 10ml de leite para cada 1g de café

## Conteúdos utilizados

- Entrada e saída de dados
- Variáveis e tipos
- Operações matemáticas
- Operadores relacionais e lógicos
- `if/else`
- `when`
- `while`
- Funções
- Null Safety (`?.` e `?:`)
- Incremento (`++`) e decremento (`--`)

## Como executar

1. Clone ou baixe este repositório.
2. Abra o projeto no IntelliJ IDEA.
3. Execute o arquivo `CafeEspecial.kt`.
4. Utilize o menu exibido no terminal.
