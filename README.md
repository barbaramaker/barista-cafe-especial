# Barista de Café Especial 

Projeto desenvolvido em Kotlin para a atividade de Coding.

O programa simula o preparo de um café especial. O usuário informa o valor do pedido, a quantidade de café, a quantidade de leite e a temperatura. A partir desses valores, o programa verifica se a receita está dentro do padrão e calcula a gorjeta.

O usuário possui até 3 tentativas para conseguir preparar a receita perfeita.

**Receita padrão:**
- Café: 20g
- Leite: 200ml
- Temperatura: 65°C
- Proporção: 10ml de leite para cada 1g de café

Durante o desenvolvimento foram utilizados entrada e saída de dados, variáveis, operações matemáticas, operadores relacionais e lógicos, `if/else`, `when`, `while`, funções e Null Safety.

**Para executar:**
1. Clone ou baixe o repositório.
2. Abra o projeto no IntelliJ IDEA.
3. Execute o arquivo `CafeEspecial.kt`.
4. Utilize o menu exibido no terminal.
